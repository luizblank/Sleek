<p>A stylish, AI-powered inventory and wishlist companion designed for fashion enthusiasts. Sleek helps users track items they desire and seamlessly transitions them into a curated digital wardrobe using advanced computer vision.</p>

<p><b>Key Technical Highlights:</b></p>
<ul>
  <li><b>AI Computer Vision</b>: Integration of Apple's Vision Framework for real-time background removal and intelligent item classification.</li>
  <li><b>Seamless Data Flow</b>: Implementation of Share Extensions and App Groups to capture items directly from external browsers and apps.</li>
  <li><b>Persistence & Performance</b>: Utilizing SwiftData for robust local storage and Core Image for high-performance image processing.</li>
  <li><b>Customization Engine</b>: A flexible UI system allowing granular control over themes, typography, and dynamic application assets.</li>
  <li><b>Tech Stack</b>: SwiftUI, SwiftData, Vision Framework, Core Image, Share Extensions.</li>
</ul>
